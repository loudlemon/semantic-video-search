Semantic Video Search Engine (In Development)

Система семантического поиска, позволяющая пользователям находить видеоконтент по смысловому запросу на естественном языке, а не по ключевым словам. Проект использует микросервисную архитектуру и современные модели машинного обучения для индексации и поиска.

🚀 Статус Проекта

Проект находится в активной фазе разработки (MVP). Базовая функциональность реализована и доступна для тестирования локально. Репозиторий регулярно обновляется.

✨ Ключевые Технологии

* Backend: Python (FastAPI), React
* AI/ML: Sentence Transformers, CLIP, BLIP
* Архитектура: Микросервисы, Гексагональная архитектура (Ports & Adapters)
* Реляционная база данных: Postgres 
* Объектное хранилище: MinIO
* Брокер: Redis

🏗️ Архитектура Системы

Проект реализован на основе микросервисной архитектуры, где каждый сервис отвечает за конкретный бизнес-домен:
* API Gateway / User UI: Принимает запросы пользователей и управляет UI.
* Search Service: Основной сервис для обработки поисковых запросов, взаимодействия с векторной БД и ранжирования результатов.
* Ingestion Service: принимает URL-адрес видео, организует загрузку, извлечение кадров, выгрузку в базу данных, отслеживает статус задания.
* Embedding Service: text-to-embedding эндпоинты
* Captioning Service: image-to-text эндпоинты

Внутри каждого сервиса применена Гексагональная архитектура (Ports & Adapters), что обеспечивает слабую связанность ядра бизнес-логики с внешними зависимостями (БД, API, очереди сообщений) и упрощает тестирование и масштабирование.
